### 1. EDA и предобработка данных
- Проверены пропуски и дубликаты

- Очищены признаки `mileage`, `engine`, `max_power`, `torque`

### 3. Модели с категориальными признаками
- `name` обработан извлечением марки (`brand`)

- Модели (Ridge, Lasso) показали переобучение: Test R2 = 0.38
- Категориальные признаки не улучшили качество

### 4. Streamlit-приложение
- Реализован веб-интерфейс `app.py`
- Ручной ввод параметров
- Загрузка CSV (с предобработкой единиц измерения)
- Визуализация коэффициентов модели
- Матрица корреляций (heatmap)
- Распределения признаков (гистограммы + KDE)
- Встроенный EDA-отчёт (ydata-profiling)

## Результаты
- **Лучшая модель**: линейная регрессия на 8 числовых признаках
- **Test R2**: 0.60
- **Наиболее важный признак**: `max_power` (мощность)
- Категориальные признаки **не улучшили** качество из-за переобучения

## Что дало наибольший прирост качества
- Стандартизация признаков
- Заполнение пропусков медианой
- Очистка `torque` (разделение на два числовых признака)

## Что не удалось сделать и почему
- Улучшить модель с помощью категориальных признаков — переобучение из-за редких категорий

- Получить качество R2 выше 0.6, необходимо дорабатывать категориальные признаки

## Оценка разработанного сервиса
- **Удобство использования**: интерфейс интуитивно понятен, два способа ввода данных (их выбор в одном месте)
- **Что получилось хорошо**: сделана предобработка входящего CSV (предполагается, что на вход могут подаваться данные, аналогичные train), графики информативны, предсказания быстрые
- **Ограничения**: модель не учитывает категориальные признаки (тип топлива, коробка передач), что могло бы повысить точность
- **Улучшения в следующей итерации**:  подобрать регуляризацию, добавить новые предобработанные категориальные признаки, которые улучшат модель, добавить больше визуализаций по категориальным признакам
